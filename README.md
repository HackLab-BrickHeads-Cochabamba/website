# HackLab BrickHeads Website

Sitio web oficial del HackLab BrickHeads - espacio hacker de conocimiento abierto en Cochabamba, Bolivia.

## Tech Stack

- **Framework:** Nuxt 3
- **UI:** Vue 3 + Tailwind CSS
- **Icons:** Lucide Vue
- **Deployment:** Node.js / Static

## Setup

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Preview

```bash
pnpm preview
```
